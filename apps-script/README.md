# ระบบแจ้งชำระเงิน — ฉบับ Google Apps Script + Google Sheets

ระบบเดียวกันทั้งหมด แต่ทำงานบน **Google Apps Script** โดยใช้ **Google Sheets เป็นฐานข้อมูล**
และใช้ **Google Drive เก็บไฟล์สลิป** — ไม่ต้องเช่าเซิร์ฟเวอร์ ไม่ต้องติดตั้งโปรแกรมใด ๆ
ไม่มีค่าใช้จ่าย ใช้เพียงบัญชี Google ของโรงเรียน

> ต้องการฉบับที่ติดตั้งบนเซิร์ฟเวอร์ของโรงเรียนเอง (Node.js + SQLite)?
> ดูที่ [`../README.md`](../README.md)

## ติดตั้งใน 8 ขั้นตอน (ใช้เวลาประมาณ 10 นาที)

ไม่ต้องใช้ `clasp` ไม่ต้องใช้บรรทัดคำสั่ง ทำผ่านเว็บเบราว์เซอร์ได้ทั้งหมด

### ขั้นที่ 1 — สร้างไฟล์ Google Sheets

1. เข้า <https://sheets.new> เพื่อสร้างสเปรดชีตเปล่า
2. ตั้งชื่อไฟล์ เช่น **"ระบบแจ้งชำระเงิน - โรงเรียนทุนวิทยาคม"**

> ใช้บัญชี Google ของโรงเรียน (หรือบัญชีที่ต้องการให้เป็นเจ้าของข้อมูล) เพราะไฟล์นี้คือฐานข้อมูลทั้งหมดของระบบ

### ขั้นที่ 2 — เปิดหน้าต่างเขียนสคริปต์

ที่เมนูของสเปรดชีต เลือก **ส่วนขยาย (Extensions) → Apps Script**
จะมีแท็บใหม่เปิดขึ้นมาพร้อมไฟล์ `Code.gs` ที่ว่างเปล่า

### ขั้นที่ 3 — เปิดการแสดงไฟล์ตั้งค่า (manifest)

ในหน้าต่างสคริปต์ กดรูปเฟือง **⚙️ การตั้งค่าโปรเจกต์ (Project Settings)**
แล้ว **ติ๊กถูก** ที่ *"แสดงไฟล์ manifest `appsscript.json` ในตัวแก้ไข"*

### ขั้นที่ 4 — คัดลอกไฟล์ทั้งหมดเข้าไป

คัดลอกเนื้อหาไฟล์ในโฟลเดอร์ `apps-script/` ของโปรเจกต์นี้ไปวางในหน้าต่างสคริปต์
**ชื่อไฟล์ต้องตรงกันทุกตัวอักษร** เพราะระบบเรียกไฟล์ HTML ด้วยชื่อ

| ลำดับ | ชื่อไฟล์ที่ต้องสร้าง | ชนิด | วิธีสร้าง |
|---|---|---|---|
| 1 | `appsscript.json` | manifest | มีอยู่แล้ว — **ลบของเดิมทิ้งแล้ววางทับ** |
| 2 | `00_Config` … `18_Demo` (19 ไฟล์) | สคริปต์ | **＋ → Script** แล้วตั้งชื่อ (ไม่ต้องพิมพ์ `.gs`) |
| 3 | `QrCode`, `Styles`, `Common`, `Index`, `Admin`, `AdminViews` (6 ไฟล์) | HTML | **＋ → HTML** แล้วตั้งชื่อ (ไม่ต้องพิมพ์ `.html`) |

รายชื่อไฟล์สคริปต์ทั้ง 19 ไฟล์

```
00_Config   01_Cache    02_Database  03_Utils     04_Setup
05_Auth     06_Api      07_PromptPay 08_Finance   09_Files
10_PublicApi 11_AdminMembers 12_AdminCollections 13_AdminPayments
14_AdminSettings 15_Reports 16_WebApp 17_Menu 18_Demo
```

> **เคล็ดลับ:** ลบไฟล์ `Code.gs` เดิมทิ้งได้เลย และวางไฟล์ตามลำดับหมายเลขเพื่อให้อ่านง่าย
> (Apps Script โหลดทุกไฟล์รวมกันอยู่แล้ว ลำดับจึงไม่มีผลต่อการทำงาน)

จากนั้นกด **💾 บันทึก**

### ขั้นที่ 5 — รันการติดตั้งครั้งแรก

1. ที่ช่องเลือกฟังก์ชันด้านบน เลือก **`setup`**
2. กด **▶ เรียกใช้ (Run)**
3. Google จะขอสิทธิ์ → กด **ตรวจสอบสิทธิ์ (Review permissions)** → เลือกบัญชี
4. หากขึ้นข้อความ *"Google hasn't verified this app"* ให้กด **ขั้นสูง (Advanced)** → **ไปที่ … (unsafe)**
   ข้อความนี้เป็นเรื่องปกติของสคริปต์ที่เขียนเอง เพราะยังไม่ได้ส่งให้ Google ตรวจสอบ
   สคริปต์นี้ทำงานอยู่ในบัญชีของท่านเองเท่านั้น
5. กด **อนุญาต (Allow)**

เมื่อรันเสร็จ ให้ดูข้อความใน **บันทึกการดำเนินการ (Execution log)** จะพบ

```
✅ ติดตั้งระบบเรียบร้อยแล้ว
  ชื่อผู้ใช้ : admin
  อีเมล     : (อีเมลของท่าน)
  รหัสผ่าน  : Cwk########
```

> 🔐 **บันทึกรหัสผ่านนี้ไว้ทันที** ระบบจะบังคับให้เปลี่ยนรหัสผ่านเมื่อเข้าสู่ระบบครั้งแรก

ระบบจะสร้างให้อัตโนมัติ

- ชีตข้อมูล **13 แผ่น** (Settings, Groups, Members, Collections, CollectionItems, Assignments, AssignmentItems, Payments, BankAccounts, Admins, Sessions, PasswordResets, AuditLogs)
- โฟลเดอร์ใน Google Drive สำหรับเก็บ **สลิปการโอนเงิน / รายงาน / ตราโรงเรียน**
- กลุ่มชั้นเรียนตัวอย่าง (ม.1/1 … ม.6/1 และคณะครูและบุคลากร)
- บัญชีผู้ดูแลระบบคนแรก

### ขั้นที่ 6 — เผยแพร่เว็บแอป

1. กด **เผยแพร่ (Deploy) → การเผยแพร่ใหม่ (New deployment)**
2. กดรูปเฟือง ⚙️ ข้าง *"เลือกประเภท"* → เลือก **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้

   | ช่อง | ค่าที่ต้องเลือก | เหตุผล |
   |---|---|---|
   | คำอธิบาย (Description) | เช่น `เวอร์ชัน 1` | ไว้จำว่าเผยแพร่ครั้งที่เท่าไร |
   | ดำเนินการในชื่อ (Execute as) | **ฉัน (Me)** | เพื่อให้ระบบเขียนลงชีตและ Drive ของโรงเรียนได้ |
   | ผู้มีสิทธิ์เข้าถึง (Who has access) | **ทุกคน (Anyone)** | ผู้ปกครองต้องเปิดดูได้โดยไม่ต้องล็อกอิน Google |

4. กด **เผยแพร่ (Deploy)** แล้ว **คัดลอก URL ของเว็บแอป**

> ⚠️ **สำคัญ** — ต้องเลือก *ทุกคน (Anyone)* ไม่ใช่ *ทุกคนที่มีบัญชี Google*
> มิฉะนั้นผู้ปกครองที่ไม่มีบัญชี Google จะเปิดหน้าเว็บไม่ได้

### ขั้นที่ 7 — ตรวจสอบลิงก์

กลับไปที่ไฟล์ Google Sheets แล้ว **รีเฟรชหน้า (F5)** จะพบเมนูใหม่ **⚙️ ระบบแจ้งชำระเงิน**
เลือก **🔗 ดูลิงก์เว็บแอป** ระบบจะแสดงลิงก์ทั้งสอง

| ใช้ทำอะไร | ลิงก์ |
|---|---|
| หน้าสำหรับนักเรียน / ผู้ปกครอง | `https://script.google.com/…/exec` |
| หน้าผู้ดูแลระบบ | `https://script.google.com/…/exec?page=admin` |

### ขั้นที่ 8 — ตั้งค่าโรงเรียนและเริ่มใช้งาน

เปิดลิงก์ผู้ดูแล → เข้าสู่ระบบ → เปลี่ยนรหัสผ่าน แล้วไปที่ **ตั้งค่าระบบ**

1. กรอกชื่อโรงเรียน ที่อยู่ เบอร์โทร อัปโหลดตราโรงเรียน
2. เพิ่ม **บัญชีรับโอน** และ **เลขพร้อมเพย์** (เพื่อให้ระบบสร้าง QR ระบุยอดอัตโนมัติ)
3. ไปที่ **สมาชิก** → นำเข้ารายชื่อจากไฟล์ CSV/Excel (มีปุ่มดาวน์โหลดไฟล์ตัวอย่าง)
4. ไปที่ **รายการจัดเก็บ** → สร้างรายการ กำหนดกิจกรรมย่อยและจำนวนเงิน
5. เลือก **กำหนดผู้ต้องชำระ** → เลือกทั้งกลุ่ม รายบุคคล หรือทุกคน
6. ส่งลิงก์หน้าสาธารณะให้ผู้ปกครอง 🎉

| เมนู | หน้าที่ |
|---|---|
| 🚀 ติดตั้ง / ตรวจสอบระบบ | สร้างชีตที่ขาดหาย ปลอดภัยแม้กดซ้ำหลายครั้ง |
| 🔗 ดูลิงก์เว็บแอป | แสดงลิงก์หน้าสาธารณะและหน้าผู้ดูแล |
| 🔑 ตั้งรหัสผ่านผู้ดูแลใหม่ | **ใช้เมื่อลืมรหัสผ่านและรับอีเมลไม่ได้** ออกรหัสผ่านใหม่ให้ทันที |

| 🧹 ล้างแคชระบบ | บังคับให้อ่านข้อมูลใหม่จากชีต (ใช้เมื่อแก้ไขชีตด้วยมือ) |
| 📊 สรุปสถานะระบบ | ดูจำนวนสมาชิก รายการ และรายการที่รอตรวจสอบ |

## ความเร็วและความเสถียร — ออกแบบมาอย่างไร

Apps Script มีข้อจำกัดเรื่องความเร็วในการเรียกใช้บริการของ Google ระบบนี้จึงออกแบบให้
**เรียกใช้บริการน้อยที่สุด** ดังนี้

### 1. อ่านทั้งแผ่นครั้งเดียว ไม่อ่านทีละเซลล์

```
❌ แบบที่ช้า  : getRange(i, j).getValue()   → 1,000 แถว = 1,000 ครั้ง (ช้ามาก)
✅ แบบที่ใช้  : getDataRange().getValues()  → 1,000 แถว = 1 ครั้ง
```

### 2. แคชอัตโนมัติพร้อมเลขเวอร์ชัน

ทุกตารางมี "เลขเวอร์ชัน" เก็บไว้ใน `PropertiesService` เมื่อมีการเขียนข้อมูล เลขนี้จะเพิ่มขึ้น
กุญแจของแคชมีเลขเวอร์ชันอยู่ด้วย **แคชเก่าจึงถูกทิ้งทันทีที่ข้อมูลเปลี่ยน** ไม่มีโอกาสอ่านข้อมูลเก่าผิดพลาด

ผลการวัดจริง

| สถานการณ์ | จำนวนครั้งที่อ่านชีต |
|---|---|
| เปิดหน้าครั้งแรก | 1 ครั้ง |
| เปิดหน้าซ้ำ (ข้อมูลไม่เปลี่ยน) | **0 ครั้ง** |
| หลังบันทึกข้อมูล | 1 ครั้ง (แล้วกลับไปเป็น 0) |
| ค้นหาสมาชิก 300 ครั้ง | **0 ครั้ง** |

### 3. ข้ามข้อจำกัด 100KB ของแคชด้วยการแบ่งท่อน

`CacheService` เก็บได้สูงสุด 100KB ต่อกุญแจ ระบบจึงแบ่งข้อมูลใหญ่เป็นท่อนละ ~90KB
เก็บเป็น `key#0`, `key#1`, … และมีหัวข้อมูลบอกจำนวนท่อน ทำให้แคชตารางสมาชิกหลายพันคนได้

### 4. ค้นหาแบบ O(1)

เมื่ออ่านตารางแล้ว ระบบจะสร้างตารางดัชนี `id → ลำดับแถว` ไว้ในหน่วยความจำ
การค้นหาด้วย `dbGet()` จึงเร็วคงที่ ไม่ว่าจะมีข้อมูลกี่พันแถว

### 5. เขียนแบบรวมกลุ่ม

การอนุมัติ 100 รายการพร้อมกัน จะรวมแถวที่อยู่ติดกันเป็นบล็อกเดียวแล้วเขียนด้วย `setValues()` ครั้งเดียว
แทนที่จะเขียน 100 ครั้ง การลบข้อมูลก็ลบจากล่างขึ้นบนเป็นบล็อก เพื่อไม่ให้เลขแถวเลื่อน

### 6. ป้องกันการเขียนชนกันด้วย LockService

ทุกการเขียนอยู่ใน `withLock_()` (รอสูงสุด 25 วินาที)
หากผู้ปกครอง 30 คนกดแจ้งชำระพร้อมกัน ข้อมูลจะถูกบันทึกเรียงกันครบทุกคน ไม่ทับกัน

### 7. ฝังข้อมูลหน้าแรกมากับ HTML

หน้าเว็บที่ส่งออกไปมีข้อมูลรายการจัดเก็บฝังอยู่แล้ว (ตัวแปร `BOOT`)
ผู้ใช้จึงเห็นข้อมูลทันทีที่หน้าโหลดเสร็จ **ไม่ต้องรอเรียก `google.script.run` อีกรอบ**

### 8. ไม่พึ่งไลบรารีภายนอกเลย

- **QR พร้อมเพย์** เขียนขึ้นเองตามมาตรฐาน ISO/IEC 18004 + EMVCo — สร้างในเครื่องผู้ใช้ ไม่ส่งข้อมูลออกนอกระบบ
- **ส่งออก Excel/CSV/PDF** ใช้ความสามารถส่งออกของ Google Sheets โดยตรง
- **ไม่มี CDN ไม่มี build step** หน้าเว็บจึงโหลดเร็วและไม่พังเมื่อบริการภายนอกล่ม

## ความปลอดภัย

| หัวข้อ | รายละเอียด |
|---|---|
| รหัสผ่านผู้ดูแล | **PBKDF2-HMAC-SHA256 6,000 รอบ** + เกลือ (salt) เฉพาะบัญชี + กุญแจลับของสคริปต์ (pepper) |
| รหัส PIN สมาชิก | เข้ารหัสด้วยวิธีเดียวกัน (2,500 รอบ) — **ในชีตไม่มี PIN ตัวจริง** |
| ล็อกบัญชีอัตโนมัติ | กรอกรหัสผ่านผิด 5 ครั้ง → ล็อก 15 นาที |
| เซสชัน | โทเคนสุ่ม อายุ 6 ชั่วโมง ตรวจทุกครั้งที่เรียก API และล้างของเก่าอัตโนมัติ |
| ลืมรหัสผ่าน | ส่งลิงก์เข้า **อีเมลที่ลงทะเบียนไว้เท่านั้น** ใช้ได้ครั้งเดียว หมดอายุ 30 นาที |
| ไฟล์สลิป | ตรวจชนิดไฟล์จริงจาก **magic bytes** ไม่เชื่อนามสกุล จำกัด 5 MB |
| สลิปซ้ำ | ตรวจลายนิ้วมือไฟล์ด้วย SHA-256 ป้องกันการใช้สลิปเดิมซ้ำ |
| การเข้าถึงสลิป | เก็บใน Drive แบบส่วนตัว ต้องมี **เลขอ้างอิง 4 หลัก + PIN** หรือเป็นผู้ดูแลจึงจะเปิดดูได้ |
| จำกัดอัตราการเรียก | ทั้งการเข้าสู่ระบบ การค้นหาสลิป และการแจ้งชำระ |
| บันทึกกิจกรรม | บันทึกทุกการเปลี่ยนแปลงพร้อมผู้กระทำและเวลา |
| สิทธิ์ 3 ระดับ | ผู้ดูแลสูงสุด / ผู้ดูแล / ผู้ดูรายงาน (ดูอย่างเดียว) |

**สิทธิ์ที่สคริปต์ขอ และเหตุผล**

| สิทธิ์ | ใช้ทำอะไร |
|---|---|
| `spreadsheets` | อ่าน-เขียนชีตซึ่งเป็นฐานข้อมูล |
| `drive` | สร้างโฟลเดอร์เก็บสลิปและไฟล์รายงาน |
| `script.external_request` | สร้างลิงก์ส่งออกรายงาน (Excel/CSV/PDF) |
| `script.send_mail` | ส่งอีเมลลิงก์รีเซ็ตรหัสผ่าน |
| `script.scriptapp` | อ่าน URL ของเว็บแอปเพื่อใส่ในลิงก์รีเซ็ตรหัสผ่าน |

| เวลาทำงานของสคริปต์ | 90 นาที/วัน | 6 ชั่วโมง/วัน |
| ส่งอีเมล | 100 ฉบับ/วัน | 1,500 ฉบับ/วัน |
| พื้นที่ Drive | 15 GB | ตามแพ็กเกจของโรงเรียน |
| เซลล์ในสเปรดชีต | 10 ล้านเซลล์ | 10 ล้านเซลล์ |

**ประมาณการสำหรับโรงเรียนขนาด 1,000 คน** — เก็บเงินเดือนละ 2 รายการ
ใช้พื้นที่ราว 2 GB/ปี (ส่วนใหญ่เป็นไฟล์สลิป) และใช้เวลาทำงานไม่ถึง 10% ของโควตารายวัน
**เพียงพอสบาย ๆ แม้บัญชี Gmail ธรรมดา**

หากใกล้เต็มพื้นที่ ให้ย้ายโฟลเดอร์สลิปของปีการศึกษาเก่าไปเก็บที่อื่น

## การอัปเดตระบบในภายหลัง

1. แก้ไขหรือวางโค้ดใหม่ในหน้าต่างสคริปต์ → **บันทึก**
2. **เผยแพร่ (Deploy) → จัดการการเผยแพร่ (Manage deployments)**
3. กดรูปดินสอ ✏️ → ช่อง *เวอร์ชัน* เลือก **เวอร์ชันใหม่ (New version)** → **เผยแพร่**

> ทำแบบนี้ **URL เดิมจะไม่เปลี่ยน** ผู้ปกครองใช้ลิงก์เดิมได้ต่อเนื่อง
> (ถ้ากด *New deployment* จะได้ URL ใหม่ ซึ่งไม่แนะนำ)

หลังอัปเดต แนะนำให้เลือกเมนู **🧹 ล้างแคชระบบ** หนึ่งครั้ง

---

## การสำรองข้อมูล

ข้อมูลอยู่ใน Google Drive ซึ่งมีประวัติการแก้ไขในตัวอยู่แล้ว แต่ควรสำรองเพิ่มเติม

- **รายเดือน:** เปิดสเปรดชีต → **ไฟล์ → สร้างสำเนา** ตั้งชื่อเป็นเดือน/ปี
- **สลิปการโอน:** อยู่ในโฟลเดอร์ *"ระบบแจ้งชำระเงิน - โรงเรียนทุนวิทยาคม/สลิปการโอนเงิน"*
- **กู้คืนรุ่นเก่า:** เปิดสเปรดชีต → **ไฟล์ → ประวัติเวอร์ชัน → ดูประวัติเวอร์ชัน**

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| ไม่เห็นเมนู **⚙️ ระบบแจ้งชำระเงิน** | รีเฟรชไฟล์ Sheets (F5) หากยังไม่ขึ้น ให้รันฟังก์ชัน `onOpen` จากหน้าต่างสคริปต์หนึ่งครั้ง |
| เปิดลิงก์แล้วขึ้น *"Script function not found: doGet"* | ยังไม่ได้เผยแพร่เป็น **Web app** หรือเผยแพร่เป็นชนิดอื่น — ทำขั้นที่ 6 ใหม่ |
| ผู้ปกครองเปิดลิงก์แล้วถูกบังคับให้ล็อกอิน Google | ตั้ง *Who has access* ผิด ต้องเป็น **Anyone** — แก้ที่ Manage deployments |
| ขึ้นว่า *"You do not have permission to call…"* | ยังไม่ได้อนุญาตสิทธิ์ — รัน `setup` จากหน้าต่างสคริปต์อีกครั้งแล้วกด Allow |
| ลืมรหัสผ่านผู้ดูแลและรับอีเมลไม่ได้ | ใช้เมนู **🔑 ตั้งรหัสผ่านผู้ดูแลใหม่** ในไฟล์ Sheets |
| แก้ข้อมูลในชีตด้วยมือแล้วหน้าเว็บยังแสดงของเดิม | เลือกเมนู **🧹 ล้างแคชระบบ** |
| อัปโหลดสลิปไม่ได้ | ไฟล์เกิน 5 MB หรือไม่ใช่ JPG/PNG/WebP/HEIC/PDF — ให้ถ่ายใหม่หรือย่อขนาด |
| อัปโหลดโลโก้ไม่ได้ | โลโก้ต้องไม่เกิน 32 KB แนะนำ PNG ขนาด 256×256 |
| ระบบช้าผิดปกติ | ตรวจว่ามีใครเปิดแก้ไขชีตค้างไว้หรือไม่ และลองล้างแคชหนึ่งครั้ง |

## การทดสอบ (สำหรับผู้พัฒนา)

ต้องมี Node.js 18 ขึ้นไป (ไม่ต้องติดตั้งแพ็กเกจใด ๆ)

```bash
cd apps-script/test
node test-core.js       # ตรรกะหลัก      → ผ่าน 101 รายการ
node test-reports.js    # รายงาน/ส่งออก  → ผ่าน 29 รายการ
node test-webapp.js     # หน้าเว็บ       → ผ่าน 31 รายการ
```

ชุดทดสอบใช้ `gas-shim.js` จำลอง `SpreadsheetApp`, `DriveApp`, `CacheService`,
`PropertiesService`, `LockService`, `Utilities`, `HtmlService`, `MailApp` และ `ScriptApp`
จึงทดสอบตรรกะทั้งหมดได้ในเครื่องโดยไม่ต้องเชื่อมต่อ Google
