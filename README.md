# ระบบแจ้งชำระเงินตามวัตถุประสงค์การจัดเก็บ — โรงเรียนทุนวิทยาคม

ระบบเว็บสำเร็จรูปสำหรับรับแจ้งการชำระเงินของโรงเรียน **พร้อมใช้งานทันทีโดยไม่ต้องเขียนโปรแกรมเพิ่ม**
รองรับการใช้งานบนคอมพิวเตอร์ตั้งโต๊ะ โน้ตบุ๊ก แท็บเล็ต และโทรศัพท์มือถือ

---

## ภาพรวมของระบบ

ระบบแบ่งเป็น 2 ส่วนหลักตามที่โรงเรียนต้องการ

### 1. ระบบรับแจ้ง (สำหรับนักเรียน ผู้ปกครอง และบุคลากร) — ไม่ต้องเข้าสู่ระบบ

| หน้า | เส้นทาง | หน้าที่ |
|---|---|---|
| รายการชำระเงิน | `/` | แสดงรายการจัดเก็บที่เปิดรับชำระทั้งหมด |
| ตารางผู้ต้องชำระ | `/collection.html?id=…` | ตารางรายชื่อผู้ต้องชำระ พร้อมสถานะและปุ่มแจ้งชำระ |
| ตรวจสอบสลิป | `/check.html` | กรอก **เลขอ้างอิง 4 หลัก** เพื่อดูสถานะและสลิปย้อนหลัง |
| ประวัติของฉัน | `/my.html` | สมาชิกดูรายการที่ต้องชำระและประวัติทั้งหมดของตนเอง |

**สีของปุ่มสถานะตามที่กำหนด**

| สถานะ | สีปุ่ม | ความหมาย |
|---|---|---|
| ยังไม่ชำระ | 🔴 แดง | กดเพื่อแนบสลิปการโอน |
| ไม่ผ่านการตรวจสอบ | 🔴 แดง | สลิปไม่ผ่าน แจ้งใหม่ได้ พร้อมแสดงเหตุผล |
| รอตรวจสอบ | 🟡 เหลือง | แจ้งแล้ว รอผู้ดูแลยืนยัน |
| ชำระบางส่วน | 🔵 ฟ้า | ผ่อนชำระ ยังเหลือยอดค้าง |
| ชำระแล้ว | 🟢 เขียว | ผู้ดูแลตรวจสอบและยืนยันแล้ว |
| ยกเว้นการชำระ | ⚪ เทา | ได้รับทุนหรือได้รับการยกเว้น |

**ขั้นตอนการแจ้งชำระเงิน**

1. เลือกรายการจัดเก็บ → ค้นหาชื่อตนเองในตาราง
2. กดปุ่มสีแดง → ระบบแสดงยอดที่ต้องชำระ ช่องทางการโอน และ **QR พร้อมเพย์ระบุยอดอัตโนมัติ**
3. แนบสลิป (ถ่ายจากมือถือได้ทันที) + กรอกรหัส PIN ยืนยันตัวตน
4. ระบบออก **เลขอ้างอิง 4 หลัก** และเปลี่ยนสถานะเป็น "รอตรวจสอบ" (ปุ่มเหลือง)
5. เมื่อผู้ดูแลยืนยัน สถานะจะเปลี่ยนเป็น "ชำระแล้ว" (ปุ่มเขียว) พร้อมออกเลขที่ใบเสร็จ

### 2. ระบบผู้ดูแล (ต้องเข้าสู่ระบบด้วยรหัสผ่าน) — `/admin`

| เมนู | ความสามารถ |
|---|---|
| **แดชบอร์ด** | ยอดที่ต้องเก็บ/เก็บได้/ค้างชำระ กราฟย้อนหลัง 12 เดือน ความคืบหน้ารายชุดและรายกลุ่ม |
| **ตรวจสอบการชำระ** | ดูสลิป อนุมัติ/ไม่อนุมัติพร้อมเหตุผล อนุมัติหลายรายการพร้อมกัน บันทึกรับเงินสด ออกใบเสร็จ |
| **รายการจัดเก็บ** | สร้างได้ไม่จำกัด กำหนดกิจกรรมย่อยและจำนวนเงิน เปิด/ปิดรับชำระ ทำสำเนา |
| **สมาชิก** | เพิ่มทีละคนหรือนำเข้า CSV/Excel รีเซ็ตรหัส PIN (ทีละคน/ทั้งกลุ่ม) ย้ายกลุ่ม เปิด-ปิดการใช้งาน |
| **กลุ่ม/ชั้นเรียน** | จัดกลุ่มสมาชิกเพื่อกำหนดผู้ที่ต้องชำระแบบรายกลุ่ม |
| **รายงาน** | 6 รูปแบบ ส่งออก Excel/CSV และพิมพ์เป็น PDF |
| **บันทึกกิจกรรม** | ประวัติการทำงานทุกอย่างในระบบเพื่อการตรวจสอบย้อนหลัง |
| **ตั้งค่าระบบ** | ข้อมูลโรงเรียน โลโก้ บัญชีรับโอน พร้อมเพย์ ตัวเลือกการทำงาน สำรองข้อมูล |
| **ผู้ดูแลระบบ** | จัดการบัญชีผู้ดูแล 3 ระดับสิทธิ์ ตั้งรหัสผ่านใหม่ ปลดล็อกบัญชี |

**การกำหนดผู้ที่ต้องชำระ** ทำได้ 3 แบบ คือ เลือกทั้งกลุ่ม เลือกรายบุคคล หรือสมาชิกทั้งหมด
พร้อมกำหนดยอดเงิน ส่วนลด และเลือกว่าแต่ละคนต้องชำระกิจกรรมย่อยใดบ้าง

**รายงานทั้ง 6 รูปแบบ**

1. ภาพรวมทุกรายการจัดเก็บ
2. รายงานรายชุด — ตารางผู้ต้องชำระทุกคนในรอบนั้น
3. สรุปรายบุคคล (ทุกคน) — ยอดสะสมของทุกคน กรองตามกลุ่ม/รอบ/ช่วงวันที่
4. รายบุคคล (รายคน) — แยกเป็นรอบ ๆ หรือรวมทั้งหมดที่ชำระมา
5. รายการรับชำระ (ธุรกรรม) — พร้อมคำอ่านจำนวนเงินภาษาไทย
6. รายชื่อค้างชำระ — เรียงตามจำนวนวันที่เลยกำหนด

## ความสามารถเพิ่มเติมที่จัดให้ (นอกเหนือจากที่ขอ)

| ความสามารถ | ประโยชน์ |
|---|---|
| **QR พร้อมเพย์ระบุยอดอัตโนมัติ** | สแกนจ่ายได้ทันทีตามยอดของแต่ละคน ลดการโอนผิดจำนวน (สร้างตามมาตรฐาน EMVCo ในเครื่อง ไม่ส่งข้อมูลออกภายนอก) |
| **ตรวจจับสลิปซ้ำอัตโนมัติ** | ป้องกันการนำสลิปเดิมมาใช้ซ้ำ โดยเทียบลายนิ้วมือไฟล์ (SHA-256) |
| **ใบเสร็จรับเงิน** | ออกเลขที่ใบเสร็จอัตโนมัติ พิมพ์ได้ พร้อมคำอ่านจำนวนเงินภาษาไทย |
| **ผ่อนชำระ** | เปิดให้ชำระบางส่วนหลายครั้งจนครบยอดได้ (ตั้งค่าได้รายรายการ) |
| **ยกเว้น/ส่วนลด** | รองรับนักเรียนทุนหรือกรณีได้รับการยกเว้น |
| **บันทึกรับเงินสด** | ผู้ดูแลบันทึกการรับเงินที่โรงเรียนได้ สถานะเปลี่ยนเป็นชำระแล้วทันที |
| **สิทธิ์ผู้ใช้ 3 ระดับ** | ผู้ดูแลสูงสุด / ผู้ดูแล / ผู้ดูรายงาน (ดูอย่างเดียว) |
| **บันทึกกิจกรรม** | ตรวจสอบย้อนหลังได้ว่าใครทำอะไรเมื่อไร |
| **สำรองข้อมูล** | ดาวน์โหลดไฟล์สำรองจากหน้าเว็บ หรือสั่งสำรองทั้งระบบด้วยคำสั่งเดียว |
| **โหมดมืด** | ปรับตามการตั้งค่าเครื่อง หรือสลับเองได้ |
| **รองรับวันที่แบบไทย** | แสดงเป็น พ.ศ. และชื่อเดือนภาษาไทยทั้งระบบ |
| **ปิดบังนามสกุล** | ตัวเลือกแสดงชื่อแบบปิดบังบนหน้าสาธารณะเพื่อความเป็นส่วนตัว |

## การติดตั้ง

**สิ่งที่ต้องมี:** Node.js เวอร์ชัน 18.17 ขึ้นไป ([ดาวน์โหลด](https://nodejs.org/)) — ไม่ต้องติดตั้งฐานข้อมูลแยก

```bash
# 1. ติดตั้งแพ็กเกจที่จำเป็น
npm install

# 2. ตั้งค่าเริ่มต้น (สร้างบัญชีผู้ดูแลคนแรก)
cp .env.example .env      # แล้วแก้ไขค่า SESSION_SECRET
npm run setup

# 3. เริ่มใช้งาน
npm start
```

เปิดเบราว์เซอร์ไปที่

- หน้าสำหรับสมาชิก: <http://localhost:3000>
- หน้าผู้ดูแลระบบ: <http://localhost:3000/admin>

### ทดลองใช้งานด้วยข้อมูลตัวอย่าง

```bash
npm run demo    # สร้างสมาชิก 90 คน 5 รายการจัดเก็บ และการแจ้งชำระหลากหลายสถานะ
```

### คำสั่งทั้งหมด

| คำสั่ง | ความหมาย |
|---|---|
| `npm start` | เริ่มระบบ |
| `npm run dev` | เริ่มระบบแบบรีโหลดอัตโนมัติเมื่อแก้ไขไฟล์ |
| `npm run setup` | ตั้งค่าเริ่มต้น / สร้างบัญชีผู้ดูแลคนแรก |
| `npm run reset-admin` | ตั้งรหัสผ่านผู้ดูแลใหม่จากเครื่องเซิร์ฟเวอร์ (กรณีลืมและรับอีเมลไม่ได้) |
| `npm run demo` | สร้างข้อมูลตัวอย่าง |
| `npm run backup` | สำรองฐานข้อมูลและไฟล์สลิปทั้งหมด |

## การนำไปใช้งานจริง

1. **เปลี่ยน `SESSION_SECRET`** ในไฟล์ `.env` เป็นค่าสุ่ม
   ```bash
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   ```
2. **ใช้ HTTPS** แล้วตั้ง `COOKIE_SECURE=true` และ `NODE_ENV=production`
3. **ตั้งค่า SMTP** ในไฟล์ `.env` เพื่อให้ลิงก์รีเซ็ตรหัสผ่านส่งเข้าอีเมลได้จริง
   (หากไม่ตั้งค่า ระบบยังใช้งานได้ โดยบันทึกอีเมลเป็นไฟล์ไว้ที่ `data/outbox` และแสดงใน console)
4. **สำรองข้อมูลสม่ำเสมอ** — ตั้ง cron รายวันได้ เช่น
   ```
   0 2 * * * cd /path/to/CWK-School-payment && npm run backup
   ```
5. ให้ระบบทำงานต่อเนื่องด้วย `systemd`, `pm2` หรือ Docker ตามความถนัดของโรงเรียน

ตัวอย่างไฟล์ systemd:

```ini
[Unit]
Description=CWK School Payment
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/CWK-School-payment
ExecStart=/usr/bin/node server.js
Restart=always
EnvironmentFile=/opt/CWK-School-payment/.env

[Install]
WantedBy=multi-user.target
```

## ข้อมูลและการสำรอง

ข้อมูลทั้งหมดอยู่ในโฟลเดอร์ `data/` (ไม่ถูกเก็บใน Git)

```
data/
├── app.db          ฐานข้อมูล SQLite (สมาชิก รายการจัดเก็บ การชำระเงิน)
├── uploads/        ไฟล์สลิปที่สมาชิกแนบ และโลโก้โรงเรียน
└── outbox/         อีเมลที่บันทึกไว้เมื่อยังไม่ได้ตั้งค่า SMTP
```

การสำรองข้อมูลคือการคัดลอกโฟลเดอร์ `data/` ทั้งหมด หรือใช้ `npm run backup`

## ความปลอดภัยที่ระบบมีให้

- รหัสผ่านผู้ดูแลและรหัส PIN สมาชิกเข้ารหัสด้วย **bcrypt**
- **ล็อกบัญชีอัตโนมัติ 15 นาที** เมื่อกรอกรหัสผ่านผิด 5 ครั้ง
- ป้องกัน **CSRF** ด้วยโทเคนในเซสชันและการตรวจสอบ Origin
- จำกัดอัตราการเรียก (rate limit) สำหรับการเข้าสู่ระบบ การค้นหาสลิป และการแจ้งชำระ
- ตั้งค่าความปลอดภัยของเบราว์เซอร์ด้วย **Helmet** (CSP, HSTS, X-Frame-Options ฯลฯ)
- ตรวจสอบชนิดไฟล์จริงจาก **magic bytes** ไม่เชื่อนามสกุลไฟล์
- ไฟล์สลิปไม่เปิดให้เข้าถึงตรง ต้องผ่าน API ที่ตรวจสอบเลขอ้างอิงหรือสิทธิ์ผู้ดูแล
- ป้องกัน **SQL injection** ด้วย prepared statements ทุกจุด
- ลิงก์รีเซ็ตรหัสผ่านใช้ได้ครั้งเดียว หมดอายุใน 30 นาที และ**ต้องตรงกับอีเมลที่ลงทะเบียนไว้**

## โครงสร้างโปรเจกต์

```
├── server.js              จุดเริ่มต้นของเซิร์ฟเวอร์
├── src/
│   ├── app.js             ตั้งค่า Express, ความปลอดภัย, เส้นทาง
│   ├── db/                ฐานข้อมูล SQLite และโครงสร้างตาราง
│   ├── routes/            API ทั้งหมด (สาธารณะ + ผู้ดูแล)
│   ├── services/          ตรรกะหลัก (สถานะการชำระ, พร้อมเพย์, นำเข้า, ส่งออก, อีเมล)
│   ├── middleware/        การยืนยันตัวตน, อัปโหลดไฟล์, ความปลอดภัย
│   └── utils/             ตัวช่วยภาษาไทย, สร้างรหัส, ตรวจสอบข้อมูล
├── public/                หน้าเว็บทั้งหมด (ไม่ต้องคอมไพล์)
│   ├── index.html · collection.html · check.html · my.html
│   ├── admin/             หน้าผู้ดูแลระบบ
│   ├── css/ · js/
├── scripts/               คำสั่งติดตั้ง สำรองข้อมูล และข้อมูลตัวอย่าง
└── docs/                  คู่มือการใช้งานภาษาไทย
```

**เทคโนโลยีที่ใช้:** Node.js + Express, SQLite (better-sqlite3), ExcelJS, bcrypt
ส่วนหน้าเว็บเขียนด้วย HTML/CSS/JavaScript ล้วน **ไม่ต้องคอมไพล์หรือ build**
